# Desafio de monitoramento | Cogmo Technology

Esta pasta reúne dois desafios independentes para alunos em formação:

- [Backend](back/README.md): API REST, Node.js, Express e banco SQLite.
- [Frontend](front/README.md): React, interface responsiva e integração com API.

Cada pasta agora também contém seu próprio guia detalhado em PDF, com explicações em linguagem acessível, passos sugeridos, glossário e critérios de entrega.

- [Guia PDF do desafio Backend](back/DESAFIO_BACKEND_COGMO.pdf)
- [Guia PDF do desafio Frontend](front/DESAFIO_FRONTEND_COGMO.pdf)

Cada trilha foi pensada para 16 a 24 horas de trabalho júnior. O pacote inclui starters intencionalmente incompletos, contrato de API, exemplos, fixtures gerados localmente, configuração e harnesses para demonstração.

## Início rápido

Abra somente a pasta da trilha escolhida. Cada README contém seus próprios comandos de instalação e execução. O frontend inicia com um mock local; o backend grava uma amostra fictícia no SQLite. As equipes podem integrar os dois depois que ambas as partes seguem o contrato.

## Credenciais e dados

Nenhuma chave de API, senha, conta ou serviço externo é necessário. Os arquivos .env.example contêm somente configurações locais demonstrativas. As estações e observações são sintéticas e não devem ser usadas para acompanhar rios reais ou tomar decisões de segurança.

## Referência de leitura

O PDF GUIA_DESAFIOS_COGMO.pdf apresenta o contexto comum. Para acompanhar cada trilha em mais detalhe, leia DESAFIO_BACKEND_COGMO.pdf ou DESAFIO_FRONTEND_COGMO.pdf dentro da respectiva pasta. Os READMEs trazem os comandos de execução.
