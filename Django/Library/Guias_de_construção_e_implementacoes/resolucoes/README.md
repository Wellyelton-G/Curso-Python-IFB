## Como as resoluções foram organizadas

- Cada resolução parte do **gabarito da própria aula** (pasta `gabarito/aula_NN`, como `gabarito/aula_08`), e não do final do curso.
- As resoluções de uma mesma aula podem ser aplicadas juntas, na ordem em que aparecem.
- Todo o código foi aplicado sobre o gabarito e testado. Os exercícios que pedem teste trazem o teste pronto; nos outros, há um roteiro de verificação.
- Há mais de uma forma correta de resolver quase todos os exercícios. A resolução mostrada é uma delas, escolhida por usar apenas o que já foi estudado até aquela aula.

## Sugestão de uso

Uma forma de usar este material é liberá-lo depois do prazo de entrega de cada lista, ou usá-lo na correção coletiva em sala.
